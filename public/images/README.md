# GROEarnX image assets

The public landing page and sign-in panel use a remote, editorial crypto/blockchain image from Unsplash:
- https://images.unsplash.com/photo-1639762681485-074b7f938ba0?auto=format&fit=crop&w=1500&q=85

This keeps the source URL visible for maintenance and avoids pretending the image is a GROEarnX security certification, real portfolio, or real transaction. Confirm the provider's current license and usage terms before commercial launch. The site also includes `market-orbit.svg`, a locally authored abstract fallback visual that does not represent live market data.

Dashboard imagery is intentionally restrained: a real trading interface should prioritize accurate market charts, balances, order status and risk notices over decorative stock photos.
